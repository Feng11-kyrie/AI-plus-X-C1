## 摘要

**模型上下文协议（MCP）** 是一项开放标准，它把 AI 模型与外部数据和服务连接起来，让大语言模型（LLM）能够以一致、安全的方式进行结构化的 API 调用。本文将介绍 MCP，解释它为什么对连接 AI 系统有价值，把它与 ChatGPT 插件、手工 API 集成等既有做法作比较，并深入探讨它近期对基于 OAuth 的身份认证的支持。我们还会看一点代码，观察 MCP 的实际运作。

MCP 充当 AI 工具与外部服务之间的**通用适配器**，免去了为每个工具或 API 编写定制集成代码的需要。就像 USB-C 简化了各种设备之间的连接，MCP 为 AI 模型调用外部函数、获取数据或使用预定义提示词提供了统一的方法。它的核心是：**一个接口，连接众多不同系统。**
