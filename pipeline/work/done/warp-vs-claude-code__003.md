## 隐私与安全

Warp 符合 **SOC 2** 标准，并与所有签约的 LLM 供应商执行**零数据留存**政策。客户的 AI 数据不会被留存、存储或用于训练。

Warp 的 AI 功能可在 **Settings** > **AI** 中全局关闭。

→ [进一步了解数据隐私](https://www.warp.dev/privacy)
