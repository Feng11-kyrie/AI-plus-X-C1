## 什么是工具？

在计算领域，确定性系统在给定相同输入时每次都会产出相同输出；而**非确定性**系统——比如智能体——即便起始条件相同，也可能生成各不相同的响应。

我们传统上写软件时，是在确定性系统之间建立一份契约。例如 `getWeather("NYC")` 这样的函数调用，每次调用都会以完全相同的方式获取纽约市的天气。

工具是一类新的软件，它体现的是**确定性系统与非确定性智能体之间的契约**。当用户问「我今天该带伞吗？」，智能体可能去调用天气工具，可能凭常识作答，甚至可能先追问一句地点。偶尔，智能体也可能产生幻觉，或者根本没弄明白该怎么用某个工具。

这意味着为智能体写软件时，我们必须从根本上重新思考做法：**不能再用为其他开发者或系统写函数和 API 的方式去写工具和 [MCP 服务器](https://modelcontextprotocol.io/)**，而要为智能体而设计。

我们的目标是扩大智能体能够有效发挥的作用面——让它们借助工具去采取各种成功策略，解决范围广泛的任务。所幸以我们的经验，**对智能体最「顺手」的工具，最终对人类来说也出奇地直观易懂。**
