### 与智能体协作

你甚至可以**让智能体替你分析结果并改进工具**。只需把评估智能体的记录拼接起来、粘贴进 Claude Code。Claude 擅长分析记录并一次性重构大量工具——例如，确保在新改动发生时，工具的实现与描述始终保持自洽。

事实上，本文中的大部分建议，都来自我们用 Claude Code 反复优化内部工具实现的过程。我们的评估建立在自己的内部工作区之上，复刻了内部工作流的复杂度，包含真实项目、文档与消息。

我们依靠留出测试集来确保没有对「训练用」评估过拟合。这些测试集显示，我们还能榨出额外的表现提升——甚至超出「专家级」工具实现所能达到的水平，无论那些工具是研究人员手写的，还是 Claude 自己生成的。
