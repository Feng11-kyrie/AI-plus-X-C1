## 展望

要为智能体构建有效的工具，我们需要把软件开发实践从可预测、确定性的模式，重新定向到非确定性的模式上。

通过本文描述的这套迭代式、评估驱动的方法，我们识别出了一些让工具成功的稳定规律：有效的工具被有意而清晰地定义、审慎地使用智能体上下文、能在多样工作流中相互组合，并让智能体以直觉方式解决真实任务。

未来，我们预期智能体与世界交互的具体机制会持续演进——从模型上下文协议（MCP）的更新，到底层 LLM 本身的升级。有了这套系统化、评估驱动的工具改进方法，我们就能确保当智能体变得更强时，它们所用的工具也随之共同演进。
