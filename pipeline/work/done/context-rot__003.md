## 针—问题相似度

我们用嵌入计算针—问题对的余弦相似度。为保证稳健性，我们在五个嵌入模型上取平均：text-embedding-3-small、text-embedding-3-large、jina-embeddings-v3、voyage-3-large 与 all-MiniLM-L6-v2。我们度量输入长度增加时，模型表现如何受针—问题相似度影响。

## 干扰项的影响

取一对高相似度的针—问题，我们写了四个干扰项。设置如下：

- **基线**：只有针，没有干扰项
- **单个干扰项**：针 + 一个随机位置放置的干扰项
- **多个干扰项**：针 + 全部四个干扰项随机放置

我们测试干扰项在输入长度增加时对模型表现的影响，以度量干扰项与输入长度之间的非均匀性。

## 针—草堆相似度

我们使用两个主题截然不同的草堆——Paul Graham 的文章与 arXiv 论文 [12]——并为各自写出对应的针。为度量针—草堆相似度，我们对草堆做嵌入，为每根针取出最相似的 5 个片段，再对它们的余弦相似度取平均。该过程在五个不同嵌入模型上重复，以保证稳健性。
