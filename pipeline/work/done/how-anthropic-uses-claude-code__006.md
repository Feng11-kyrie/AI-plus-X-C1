## 面向增长营销的 Claude Code

增长营销团队专注于搭建付费搜索、付费社交、移动应用商店、邮件营销与 SEO 等各渠道的效果营销体系。作为一个只有一人的非技术团队，他们用 Claude Code 自动化重复性的营销任务，并创建那些传统上需要大量工程资源才能实现的智能体工作流。

**Claude Code 的主要用例**

**自动生成 Google Ads 创意**
团队构建了一套智能体工作流：处理包含数百条既有广告及其效果指标的 CSV 文件，找出表现不佳、需要迭代的广告，并生成符合严格字数限制（标题 30 字符、描述 90 字符）的新变体。借助两个专职子智能体（一个管标题、一个管描述），系统能在几分钟内生成数百条新广告，而不必在多个广告系列中手工创建。这让他们能够规模化地测试与迭代——此前要做到这一点需要投入大量时间。

**用于批量创意生产的 Figma 插件**
他们不再为付费社交广告手工复制、编辑静态图片，而是开发了一个 Figma 插件，能识别画板并程序化地批量生成最多 100 个广告变体（替换标题与描述），把原本需要数小时复制粘贴的工作压缩到每批半秒。这让创意产出提升 **10 倍**，使团队能在关键社交渠道上测试多得多的创意变体。

**用于广告系列分析的 Meta Ads MCP 服务器**
他们创建了一个与 Meta Ads API 集成的 MCP 服务器，可以直接在 Claude Desktop 应用里查询广告系列表现、花费数据与广告效果，免去了在多个平台之间来回切换做效果分析的需要，省下关键时间——在这里每一分效率提升都能转化为更好的 ROI。

**带记忆系统的高级提示词工程**
他们实现了一套简易的记忆系统，记录各轮广告迭代中的假设与实验，使系统在生成新变体时能把此前的测试结果拉进上下文，形成自我改进的测试框架。这让系统化的实验追踪成为可能——手工根本做不到。
