### 代码生成

| **场景** | **指令** | **示例提示词** |
|---|---|---|
| 代码补全 | 给 AI 一段不完整的代码，让它基于上下文与编程语言建议或补全剩余代码。 | 「写一个 Python 函数，计算给定数字的阶乘。」 |
| 代码翻译 | 指明源语言与目标编程语言，使 AI 能在保留功能与语法的前提下翻译代码。 | 「把下面这段 Python 代码翻译成 JavaScript：def greet(name): print('Hello,', name)」 |
| 代码优化 | 让 AI 分析现有代码，并就效率、可读性或性能提出改进建议。 | 「优化下面这段 Python 代码，缩短其执行时间。」 |
| 代码调试 | 给 AI 含有错误的代码，让它找出问题并给出可能的解决方案。 | 「调试下面这段 Java 代码，并解释它为什么抛出 NullPointerException。」 |
