[模型上下文协议（MCP）](https://modelcontextprotocol.io/docs/getting-started/intro)能让 LLM 智能体拥有多达数百个工具去解决真实世界的任务。但我们要如何让这些工具**效用最大化**？

本文介绍我们在各类智能体 AI 系统中提升表现的最有效技术¹。

我们先讲如何：

- 构建并测试你的工具原型
- 与智能体一起对你的工具做全面评估
- 与 Claude Code 这类智能体协作，自动提升工具的表现

最后，我们给出在这一过程中总结出的高质量工具编写原则：

- 选择该实现（以及**不该**实现）的工具
- 用命名空间为工具划定清晰的功能边界
- 从工具向智能体返回有意义的上下文
- 为 Token 效率优化工具响应
- 对工具描述与规格说明做提示词工程

*构建评估能让你系统地度量工具的表现。你可以用 Claude Code 针对这套评估自动优化你的工具。*
