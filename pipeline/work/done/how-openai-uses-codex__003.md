最佳实践

**用 AGENTS.md 提供持久上下文**
维护一个 AGENTS.md 文件，帮助 Codex 在你的仓库里跨多次提示更有效地工作。这类文件通常包含命名约定、业务逻辑、已知的怪癖，或 Codex 无法仅凭代码推断出的依赖关系。关于如何组织你的 AGENTS.md 文件，可查阅官方文档。

**借助「Best of N」改善输出**
Best-of-N 功能让你针对单个任务同时生成多个回答，从而快速探索多种方案并挑出最好的那个。对于更复杂的任务，你可以审阅若干轮迭代，并组合不同回答的部分内容，得到更强的结果。
