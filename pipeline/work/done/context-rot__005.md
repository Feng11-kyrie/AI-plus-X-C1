# 针—问题相似度

在真实应用中，模型常被期望处理含糊任务、并在不依赖精确字面匹配的情况下识别相关信息。例如，智能体拿到的任务是在一个大语料库中检索时，用户很少会为相关部分指定精确关键词。模型必须自行推断相关性。

我们改变针—问题对的相似度，以它们嵌入的余弦相似度来量化。我们发现：**针—问题相似度越低，模型表现随输入长度增加而下降得越显著。** 这更贴近现实场景——那里精确的问答匹配很少见，而语义上的含糊会加剧长输入处理的难度。
