## 面向安全工程的 Claude Code

**团队成效**

**缩短故障解决时间**
原本需要 10–15 分钟人工扫代码的基础设施调试，现在约 5 分钟。

**改善安全评审周期**
用于安全审批的 Terraform 代码评审快得多，开发者不必再干等安全团队批准。

**增强跨职能贡献**
团队成员能在几天内（而非几周构建上下文之后）对项目做出有意义的贡献。

**更好的文档工作流**
从多个来源整合出的排障指南与运维手册，造就更高效的调试流程。

**安全工程团队的头号建议**

**大量使用自定义斜杠命令**
整个 monorepo 里所有自定义斜杠命令的实现，有 **50%** 来自安全工程。这些自定义命令简化了特定工作流，也加快了重复性任务。

**先让 Claude 说**
他们不再为了要一段代码片段而问很具体的问题，而是让 Claude Code「边做边提交」，让它自主工作、定期检查，从而得到更全面的解决方案。

**把它用在文档上**
除了编码，Claude Code 在整合文档、生成结构化输出方面也很出色。他们提供写作样本与格式偏好，就能直接得到可在 Slack、Google Docs 及其它工具中使用的文档，避免在界面之间反复切换的疲劳。

## 面向推理的 Claude Code

推理团队负责管理记忆系统——在 Claude 读取你的提示词并生成响应时，用于存储信息的系统。团队成员（尤其是刚接触机器学习的人）可以大量借助 Claude Code 来弥合这一知识鸿沟、加快工作。

**Claude Code 的主要用例**

**理解代码库与上手**
加入复杂代码库时，团队高度依赖 Claude Code 来快速理解架构。他们不再手动搜索 GitHub 仓库，而是让 Claude 找出哪些文件调用了特定功能，几秒就能得到结果，而不必问同事或手工搜索。

**生成覆盖边界情况的单元测试**
写完核心功能后，他们让 Claude 编写全面的单元测试。Claude 会自动补上被遗漏的边界情况，把原本要耗费大量脑力的工作压缩到几分钟完成，相当于一位可随时审阅的编码助手。

**解释机器学习概念**
由于没有机器学习背景，团队成员依赖 Claude 来解释模型特有的函数与设置。原本需要一小时谷歌搜索与读文档的事，现在 10–20 分钟就能完成，研究时间减少 **80%**。

**跨语言代码翻译**
在不同编程语言中测试功能时，他们说明想测什么，Claude 就用所需语言（例如 Rust）写出逻辑，从而不必为测试专门去学一门新语言。

**命令回忆与 Kubernetes 管理**
不必再记复杂的 Kubernetes 命令，他们直接问 Claude 正确语法，比如「怎么获取所有 Pod 或部署状态」，就能得到基础设施工作所需的确切命令。
