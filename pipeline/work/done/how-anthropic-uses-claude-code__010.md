## 面向法务的 Claude Code

**工作方式与影响**

**在 Claude.ai 里规划，在 Claude Code 里构建**
他们采用两步流程：先用 Claude.ai 头脑风暴与规划，再转到 Claude Code 做实现，并要求它放慢节奏、一步步来，而不是一次性输出全部内容。

**视觉优先的做法**
他们经常用截图告诉 Claude Code 希望界面长什么样，然后基于视觉反馈迭代，而不是用文字描述功能。

**原型驱动的创新**
他们强调要克服分享「傻气」或「玩具式」原型的恐惧——因为这些演示会启发他人看到自己此前没想到的可能性。

**安全与合规意识**

**对 MCP 集成的顾虑**
作为产品律师，他们会立刻识别出深度 MCP 集成带来的安全影响，指出当 AI 工具接触到更多敏感系统时，保守的安全姿态会形成障碍。

**合规工具的优先级**
他们主张在 AI 能力扩张的同时尽快构建合规工具，认识到要在创新与风险管理之间取得平衡。

**法务部门的头号建议**

**先在 Claude.ai 里做充分规划**
用 Claude 的对话界面把整个想法梳理完整，再转到 Claude Code。然后让 Claude 把所有内容总结成一份可执行的分步提示词。

**渐进地、可视化地推进**
让 Claude Code 放慢节奏、一次实现一步，这样你复制粘贴时不会不知所措。大量使用截图来展示你希望界面长什么样。

**不要因为不完美就不敢分享原型**
克服把「玩具」项目或未完成工作藏起来的冲动——分享原型能帮别人看到可能性，也会在那些平时不怎么往来的部门之间激发创新。
